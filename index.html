One step to your live dashboard

This GitHub Pages address is showing a setup page. The live options dashboard needs a Python server to fetch Delta market data; GitHub Pages only serves static files.

Why you saw a 404: GitHub Pages looks for an index.html in the selected publishing folder. The dashboard itself is served by the Python app, so it cannot run directly on GitHub Pages.
  1. Click Deploy the dashboard and sign in to Render.
  2. Connect devpatel2312/Deltaexchange and review the render.yaml Blueprint.
  3. Choose Deploy Blueprint. Render will provide the public .onrender.com dashboard URL.
